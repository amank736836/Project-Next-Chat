# Requirements — Stealthy Note

This folder contains functional, non-functional, and business rule requirements.

Each requirement has a unique ID for traceability.

## Files

| File | Description |
|------|-------------|
| `functional-requirements.md` | What the system must do |
| `non-functional-requirements.md` | How the system must perform |
| `business-rules.md` | Business logic constraints |

## ID Convention

- `REQ-F-xxx` — Functional requirements
- `REQ-NF-xxx` — Non-functional requirements
- `REQ-BR-xxx` — Business rules
