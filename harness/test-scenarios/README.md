## ID Convention

`SCN-<type>-<number>`

- `SCN-SM-xxx` — Smoke
- `SCN-FN-xxx` — Functional
- `SCN-NG-xxx` — Negative
- `SCN-EC-xxx` — Edge Cases
- `SCN-IT-xxx` — Integration
- `SCN-API-xxx` — API
- `SCN-DB-xxx` — Database
- `SCN-UI-xxx` — UI
- `SCN-PF-xxx` — Performance
- `SCN-SEC-xxx` — Security
- `SCN-RG-xxx` — Regression
